Flash a gateway

Install the gateway firmware on a new board, or reinstall it on one that won't start. You need an ESP32-S3 board with at least 4 MB of flash, a USB data cable, and Chrome or Edge on a computer. The flasher checks that the board suits the firmware you choose. Once a gateway is running, install updates from the app instead.

This browser can't talk to USB serial devices.

Open this page in Chrome or Edge on a Windows, Mac, Linux or ChromeOS computer.

1Choose the firmware

Use a full image, such as openrv-gateway-full.bin from a release or from idf.py merge-bin. It holds the bootloader, partition table and firmware together.

2Connect the board

Plug the board in with a data cable and press Connect. On boards with two USB ports, either works. If it isn't listed or won't connect, hold the BOOT button, press and release RESET, release BOOT, and try again.

    3Install

    This replaces everything on the board, including a gateway's saved devices, settings, alert rules and the phones it knows. Afterwards it's a new gateway, set up again with its new QR code.

    Advanced
    A full image goes at 0x0. Change this only for images built for another address.

    4Make your phone its owner

    Scan this with the phone that will own the gateway. It opens the OpenRV app, which pairs with the gateway and becomes its owner. Owners can then let other phones in from the app.

    Gateway
    Setup code

    Keep this with the gateway: the code works until a phone owns it, and again after a factory reset (hold the BOOT button 10 seconds). Reinstalling makes a new code. Without it, hold BOOT 3 seconds and set the gateway up from the app within 2 minutes.

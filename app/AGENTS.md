Notes for AI coding agents working on the OpenRV app. People should start with [CONTRIBUTING.md](../CONTRIBUTING.md).

This is an Expo (React Native) app for Android that talks to the OpenRV gateway over Bluetooth. The gateway owns devices, settings and alert rules; the app shows them and keeps only per-phone preferences ([docs/architecture.md](../docs/architecture.md)).

## Expo changes between SDKs

APIs you remember may be renamed, moved or removed. Before touching an Expo or React Native API, read the `expo` major version in `package.json` and check the matching docs at `https://docs.expo.dev/versions/v<major>.0.0/` (or https://docs.expo.dev/llms.txt).

## Commands

```bash
npx expo install <package>  # add dependencies this way, so versions match the SDK
npm run typecheck           # tsc --noEmit
npm test                    # jest
npm run format              # prettier
```

Run typecheck, tests and `npx prettier --check src` before calling a change done; CI runs the same.

## Layout

- Routes live in `src/app/` (Expo Router); everything else is outside it: `src/protocol/` (the gateway protocol, mirroring `protocol/schema.json`), `src/store/`, `src/components/`, `src/features/`.
- Local native modules (Kotlin) are in `modules/`; they're linked automatically.
- `android/` is generated by `npx expo prebuild`; don't edit it by hand. Configure native behaviour in `app.json`, `app.config.ts` and `plugins/`.
- A new native module or library with native code needs a rebuilt app; Expo Go can't run it.
